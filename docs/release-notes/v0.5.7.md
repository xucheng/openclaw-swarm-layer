# v0.5.7

Reliability patch release for Daily Papers-style cron workflows, based on the published `0.5.6` package line.

## Highlights

- Specs can now mark phases as `[parallel]` or `[sequential]`; default behavior remains sequential for existing specs.
- Parallel phases fan out independent tasks and form a barrier for the following phase.
- `swarm run --all-ready --parallel N` can drain dependency-satisfied queued tasks, including queued-only workflows.
- `swarm run --sync-active` and `swarm status --sync` let cron and operators poll active ACP runs before dispatch/status decisions.
- Downstream tasks are promoted to `ready` after no-review completions, ACP sync completions, and review approvals.
- Docs redaction is now enforced in CI, `release:check`, and `prepublishOnly`.
