# v0.5.11

ClawHub skill/package alignment recovery release.

## Highlights

- Added `npm run release:commands`, which generates GitHub and ClawHub publish commands from a clean release commit instead of relying on hand-typed source metadata.
- ClawHub package publishing now uses the absolute staged package path and `SOURCE_COMMIT="$(git rev-parse HEAD)"` metadata.
- ClawHub skill publishing now uses `clawhub --workdir "$REPO_ROOT" skill publish "$REPO_ROOT/skills/swarm-layer"` so the standalone skill body is read from the intended repository.
- Release consistency checks now verify the publish-command guardrails, explicit skill workdir, absolute package path, and post-publish checks for both standalone and package-embedded skill content.
- This version supersedes the non-overwritable `0.5.10` ClawHub publication mismatch where package source metadata and standalone skill body content could not be corrected in-place.

## Verification

- `npm run release:check` - build, 62 unit files / 435 tests, 20 e2e files / 26 tests, docs redaction, release consistency, npm pack dry-run, and ClawHub package staging
