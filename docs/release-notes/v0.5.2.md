# v0.5.2

OpenClaw `2026.4.26` compatibility and release packaging update.

## Highlights

- Updated plugin SDK imports to current public subpaths.
- Preferred `runtime.config.current()` for ACP runtime config snapshots, with `loadConfig()` fallback for older hosts.
- Registered the `swarm` CLI with descriptor metadata only, so current OpenClaw shows one CLI command entry.
- Hardened ACP host-root detection for symlinked and mixed OpenClaw installs while preserving mini layouts that keep bundled `acpx` dependencies in the state package.
- Refreshed release metadata for npm, GitHub, ClawHub package, and ClawHub skill publication.
