# v0.5.10

ACP runtime-mode and ClawHub skill alignment hotfix.

## Highlights

- Codex ACP sessions now apply runtime mode `auto` before the first turn, so workflow tasks are not stranded in the upstream default `read-only` mode.
- Swarm Layer now captures asynchronous ACP turn failures and enriches generic `Internal error` statuses from the Codex ACP wrapper stderr diagnostics.
- Added `acp.defaultRuntimeMode` for explicit operator control when a different ACP mode is required.
- Added release consistency checks to keep npm, OpenClaw manifest, GitHub release notes, ClawHub package metadata, and `skills/swarm-layer/SKILL.md` aligned.
- This patch release lets ClawHub package and skill move together after the published `0.5.9` skill body did not match the intended release content.
