# v0.5.9

ACP backend discovery patch for current OpenClaw installs that keep `acpx` in the state npm-project cache.

## Highlights

- Swarm Layer now discovers `@openclaw/acpx` under `npm/projects/openclaw-acpx-*/node_modules/@openclaw/acpx` when OpenClaw does not expose a legacy `plugins.installs.acpx.installPath`.
- `dist/index.js` is now accepted as an `acpx` service module candidate, matching the current npm-project package layout.
- Added regression coverage for npm-project `acpx` service discovery.
- Release metadata is aligned for npm, GitHub, ClawHub package, and ClawHub skill at `openclaw-swarm-layer@0.5.9`.
